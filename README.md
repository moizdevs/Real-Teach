# Real Teach — scroll-driven 4D website

Buy · Sell · Repair inverters — near Jhang Road, Faisalabad.

## Run it
The page uses ES modules, so open it through a web server (not by double-clicking):

    python3 -m http.server 8000      # then open http://localhost:8000

## Go live (free)
Upload this whole folder to Netlify Drop (app.netlify.com/drop), GitHub Pages or Cloudflare Pages.

## Add your phone number
Open `main.js`, set `CONTACT.phoneIntl` to digits only, e.g. `"923001234567"`.
That wires every "Call" and "WhatsApp" button.

## Edit the text
All copy lives in `index.html` (captions inside `#film`, sections below it).
